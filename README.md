# Analog Glitch Portrait

A Codex skill for restyling a supplied portrait as an analog damaged-print glitch collage while preserving identity, facial geometry and the source aspect ratio.

The visual system uses fine print grain, source-derived shadow blocks and contrasting colors, aligned eye-region panels, grids and restrained circular arcs. The skill's workflow and its bundled visual references are in this repository.

## Contents

- `SKILL.md`: skill entry point and workflow
- `agents/`: Codex interface metadata
- `references/`: style and eye-panel guidance
- `assets/`: structural and surface references
